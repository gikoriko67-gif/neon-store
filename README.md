# Статический сайт магазина и обменника

Это версия на чистом HTML, CSS и JavaScript. Сервер, база данных, Node.js и Docker для публикации не нужны.

## 1. Настрой реквизиты

Открой `config.js` и замени значения:

- `storeName` — название сайта;
- `productName` — название продукта;
- `usdtWalletAddress` — адрес USDT в сети TRC20;
- `starsPaymentUrl` — готовая ссылка оплаты Telegram Stars;
- `supportTelegram` — ссылка на Telegram поддержки;
- цены и курс — при необходимости.

Если реквизит не заполнен, сайт покажет подсказку и не будет выдумывать адрес или ссылку.

**Важно:** это витрина с заранее заданными реквизитами. Она не принимает и не подтверждает платежи, не хранит заявки и не проверяет транзакции. Не называй заказ оплаченным только на основании нажатия кнопки.

## 2. Проверка на компьютере

Можно просто открыть `index.html` в браузере. Для проверки копирования адреса лучше открыть через локальный сервер, но для просмотра интерфейса это не обязательно.

## 3. Публикация на GitHub Pages

1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Создай новый публичный репозиторий, например `neon-store`.
3. Распакуй архив и загрузи в корень репозитория файлы `index.html`, `style.css`, `app.js`, `config.js`, `README.md`.
4. В репозитории открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
7. Через несколько минут GitHub Pages покажет адрес сайта в том же разделе.

После изменения `config.js` загружай обновлённый файл в репозиторий — сайт обновится автоматически после публикации.

## 4. Безопасность

Все значения в `config.js` публичны: любой посетитель может посмотреть их в исходном коде. Не помещай туда пароли, приватные ключи, seed-фразы или секретные API-токены. Публикуй только адрес, который предназначен для получения платежей.


## Страница оплаты обмена

Кнопка «Обменять USDT на RUB» открывает `payment.html`. Там посетитель выбирает выплату на телефон или карту, вводит номер и получает адрес для перевода USDT TRC20.

Адрес обменного кошелька в этой версии задан в `payment.js` как `TWNe16cgaRHS9APMiVH9DBQTFDxq6S73eF`.

Введённый номер выплаты не сохраняется на сайте. При нажатии «Сообщить о переводе в Telegram» он включается в текст сообщения поддержке. Пользователь сам решает, отправлять ли это сообщение.

Статический сайт не проверяет транзакции, не принимает заявки на сервере и не выполняет выплаты. Перед использованием проверь, что адрес кошелька и условия обмена принадлежат тебе и актуальны.


## Обновлённый сценарий обмена

Реквизиты выплаты (номер телефона или номер карты) пользователь вводит на главной странице в блоке обменника. После нажатия «Обменять USDT на RUB» сайт временно сохраняет выбранный способ и реквизит в `sessionStorage` текущей вкладки и открывает `payment.html`. На странице перевода отображаются сумма USDT, расчётная выплата в RUB, способ/реквизит выплаты, сеть TRON (TRC20) и адрес кошелька.

Номер выплаты не добавляется в URL и не отправляется на сервер. Он существует только в хранилище вкладки браузера и отображается на странице перевода. Сайт остаётся статической витриной: не принимает и не подтверждает платежи автоматически и не гарантирует выплату.


## Продажа Telegram Stars

Добавлен раздел продажи Stars с минимальным количеством по умолчанию 300 ⭐. Пользователь вводит количество, выбирает выплату на телефон или карту, указывает реквизиты и переходит на страницу с суммой отправки, суммой «К получению», реквизитами выплаты и ссылкой на Telegram-бота.

Перед публикацией заполните в `config.js`:
- `starsSellRateRub` — курс в рублях за 1 Star (сейчас установлен 1 ₽ за 1 ⭐);
- `starsSellBotUrl` — публичная ссылка на Telegram-бота, который действительно принимает Stars и показывает пользователю корректный способ отправки.

Установлены курс 1 ₽ за 1 ⭐ и ссылка на Telegram-бота `https://t.me/TGbot` (@TGbot). Проверьте, что этот бот действительно принимает Stars и показывает корректный способ отправки. Сам статический сайт не принимает Stars, не проверяет поступление и не выполняет выплаты.


## NeuroGram: оплата USDT

В карточке товара указано название NeuroGram и описание: снятие спамблока, VPN в Telegram, запуск мода без VPN. Кнопка оплаты открывает `neurogram-payment.html` с суммой товара и адресом TRC20.

На странице NeuroGram и на странице обмена оставлена только кнопка «Отправил», без поля TXID. Нажатие подготавливает сообщение для поддержки с деталями покупки/обмена; оператор проверяет перевод вручную. Укажите реальную ссылку поддержки в `supportTelegram`. Для этого обязательно укажите реальную ссылку поддержки в `supportTelegram` (например, `https://t.me/your_support_username`).

**Важно:** GitHub Pages — статический хостинг. Эта версия не выполняет автоматическую проверку блокчейна, не принимает заявки на сервере и не выдаёт ключ автоматически. Для автоматической проверки TXID, защиты от поддельных заявок и выдачи уникальных ключей нужен сервер/backend и хранилище ключей. Не выдавайте ключ только по нажатию кнопки или скриншоту.


## Видео NeuroGram

В карточке товара встроен HTML5-плеер, который загружает видео `1119(1).mp4` из корня репозитория GitHub Pages. Поместите этот файл рядом с `index.html` (в корень репозитория). Плеер использует `preload=metadata`, поэтому посетитель не загружает всё видео заранее — данные подгружаются при воспроизведении. GitHub web upload ограничивает размер файла; если GitHub не принимает файл, уменьшите его или используйте отдельное видеохранилище.

**Важно:** кнопка «Отправил» не может сама проверить блокчейн. Без TXID, серверной проверки и идентификатора заказа поддержка получает только уведомление пользователя с деталями заказа. Не подтверждайте оплату и не выдавайте ключ только по нажатию кнопки.
